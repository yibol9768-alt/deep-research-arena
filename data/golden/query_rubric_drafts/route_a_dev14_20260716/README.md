# Route A Dev-14 Rubric 草案

生成日期：2026-07-16

本包包含 14 道题、58 个等权必要要求。所有文件均为 `draft`：只根据公开 query 和刘弈博访谈记录生成，未查看答案键、evidence graph、证据 URL 或 agent 报告，也尚未做 evidence answerability audit。

每个 atom 的运行时通过条件是：

```text
AtomPass
  = RequirementMatched
  AND LocalCitationBound
  AND ValidSource
  AND RelevantEvidenceObserved
```

单题分数为通过 atom 数除以 required atom 数；总体分数对可归责任务做宏平均。URL fabrication rate 单独报告，不与覆盖率相乘或相加。

## 01 `dr_cross_deep_0001`

1. 判断高价耳机的额外价值是否超出品牌溢价。
2. 判断主动降噪是否有实际效果。
3. 判断高级蓝牙编码是否有实际作用。
4. 结合公交和嘈杂办公室场景，推荐不同价位的耳机并解释理由。

## 02 `dr_cross_deep_0002`

1. 判断深烘焙咖啡因、咖啡豆变陈等说法的真假。
2. 比较题中列出的咖啡豆与器材入门选择。
3. 给出可实际执行的新手冲泡方法。
4. 推荐入门方案，并考虑学习成本和器材吃灰风险。

## 03 `dr_cross_deep_0003`

1. 判断耳塞降噪是否因物理结构而必然弱于头戴式。
2. 说明耳塞与便携音箱方案如何拆分 250 美元预算。
3. 比较单买头戴式与耳塞加音箱对办公室、露营的取舍。
4. 给出 250 美元的最终购买方案。

## 04 `dr_cross_deep_0004`

1. 比较新无反、二手单反套装和其他现实方案，并考虑短期淘汰风险。
2. 汇总真实摄影用户给新手的建议。
3. 给出约 800 美元的具体设备与预算方案。

## 05 `dr_cross_deep_0005`

1. 判断功率、360 度声音、IPX7、被动振膜、蓝牙高清音频及大音量失真的物理意义和营销边界。
2. 核查泳池或海滩真实用户是否认可这些宣传。
3. 推荐一款宣传与实际表现相符的便携音箱。

## 06 `dr_cross_deep_0006`

1. 判断真无线耳塞的电池和连接衰退是普遍必然问题，还是负面案例被放大。
2. 调和商品高评分与爱好者社区“耳塞是消耗品”的冲突。
3. 如果仍建议购买，推荐一款相对耐用的真无线耳塞。

## 07 `dr_cross_deep_0007`

1. 解释头戴式耳机的主要长期损坏原因。
2. 判断无线耳机是否必然受到电池寿命限制。
3. 判断可更换耳垫和线材是否真正延长寿命。
4. 汇总接近十年日常使用的长期用户经验。
5. 推荐一副符合十年使用目标的头戴式耳机。

## 08 `dr_cross_deep_0008`

1. 判断真无线耳塞在哪个价位开始出现明显的音质收益递减。
2. 判断 aptX 等编码是否改变分界点，以及什么条件下能够听出差别。
3. 比较同时使用过廉价与旗舰耳塞的用户经验。
4. 给出建议停止加价的预算位置。
5. 在该预算附近推荐一款耳塞。

## 09 `dr_cross_deep_0009`

1. 解释耳机从有线接口转向无线的过程。
2. 解释音频通过蓝牙传输时发生了什么。
3. 判断当前有线耳机是否仍有实际音质优势。
4. 比较当前用户选择有线或无线后的满意与后悔经验。
5. 推荐一副符合分析结论的入门耳机。

## 10 `dr_cross_deep_0010`

1. 判断眼镜腿是否显著破坏耳罩密封和降噪表现。
2. 在发动机噪声、十小时舒适、眼镜贴合和小背包约束下比较三种形态。
3. 汇总戴眼镜的高频飞行用户经验。
4. 推荐一个同时适合背包、面部贴合和长途飞行的选择。

## 11 `dr_cross_deep_0011`

1. 比较便宜热插拔键盘加后续升级与用完整预算购买知名成品的取舍。
2. 比较线性和段落轴对办公写作与射击游戏的适配。
3. 解释约 120 美元价位真正重要的特性。
4. 汇总购买不同方案的用户后悔点。
5. 给出符合 120 美元预算和混合用途的购物车方案。

## 12 `dr_cross_deep_0012`

1. 判断 8000 Hz 回报率的物理优势和人类可感知程度。
2. 判断光轴与低去抖延迟的实际优势和可感知程度。
3. 判断全键无冲的实际作用。
4. 调合买家“瞄准变好”的评价与物理限制、安慰剂解释。
5. 推荐一款包含真正有用特性的合理价位键盘。

## 13 `dr_cross_deep_0013`

1. 调和接近五星的评分与爱好者关于连击、保修问题的负面经验。
2. 解释键盘连击或 chatter 的原因。
3. 判断连击问题是否可修复以及修复限制。
4. 在职业打字可靠性约束下给出购买建议。

## 14 `dr_cross_deep_0014`

1. 解释轴体、键帽、卫星轴、电路板和线材等真实长期故障模式。
2. 判断 5000 万或 1 亿次按键寿命对现实耐用性的预测价值。
3. 汇总多年重度日用仍可靠的长期用户经验。
4. 推荐一款符合十年目标的真正 BIFL 键盘。
