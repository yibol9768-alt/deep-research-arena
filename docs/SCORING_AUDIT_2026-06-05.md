机制要点:单判官仍各有 ~36% 位置锁死,但**三家锁死的场子互不重叠**,多数票互救后只剩
14% 真平局 —— PoLL(arXiv 2404.18796)的结论在本数据上复现。

## 运维教训(已固化为协议)

1. **对战级 checkpoint 必须存在**:一次暂停损失 400 场后实现;此后两次 WSL 整机重启
   均零损失续跑。
2. **看门狗要能救"挂死"不只救"死亡"**:checkpoint 若干分钟不动且进程仍在 → 主动杀掉
   触发续跑(v2 已实现)。
3. **WSL 重启后并发长连接易卡死**(单发 curl 正常):缓解 = 调低 JUDGE_TIMEOUT_S
   (180→45)+ 降低并发(3→2),小步快跑。
4. WSL 内部机制救不了 WSL 本身:Windows 侧 `DRA_StackGuard` 计划任务每 5 分钟执行幂等
   boot.sh(用户授权安装;卸载:`schtasks /Delete /TN DRA_StackGuard /F`)。
5. 远程命令一律 `ssh 'bash -s' <<heredoc`;单行命令会被 Windows cmd 引号粉碎。
