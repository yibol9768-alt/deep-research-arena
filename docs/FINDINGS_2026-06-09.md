# DeepResearchArena 研究进展与发现(截至 2026-06-09)

> 面向汇报:这一周不是在堆功能,而是在评测方法学上得到了一个**可量化、可复现、且有些反直觉的实证发现**,并据此确立了一套防御性打分方法。下面按"发现 → 证据 → 为什么重要 → 局限 → 下一步实验"组织。

---

## 核心发现(一句话)

**在深度研究(Deep Research)任务上,LLM 判官的偏好与"引用是否真实可达"是解耦的;当我们固定脚手架、只替换基座大模型时,这种解耦甚至变成负相关——判官越偏爱的模型,它引用的来源反而越打不开。**

这说明:**只用 LLM-as-judge 给深度研究打分是可以被"流畅的编造"刷榜的。** 必须引入一个判官无关的接地(grounding)信号来纠偏。这正是我们这周确立的方法贡献。

---

## 发现一:判官偏好 ⟂ 引用接地(主结果)

我们对每个被测系统同时测两个量:

1. **判官 Elo**:3 判官陪审团(PoLL)成对比较 → Bradley-Terry Elo(衡量"读起来谁更好")。
2. **接地分**:`(引用可达率 reachability% + 引文核实率 quote%) / 2`,**完全不依赖判官 API**,直接在一个不可变的沙箱网络里验证每条引用是否真打得开、引文是否真在被引页面上(衡量"内容是否站得住")。

### 1a) 框架榜(12 个 agent 框架,各用其默认配置)

Spearman 秩相关 **ρ(判官 Elo, 接地) = 0.32**(弱正相关),且出现大量排名反转:

| 判官排名 | 接地排名 | 系统 | 判官 Elo | 接地分 | |
|---|---|---|---|---|---|
| #1 | #2 | claude-code | 1166 | 88% | |
| #2 | **#11** | gpt-researcher | 1147 | **3%** | ← 判官第 2,引用几乎全打不开 |
| #3 | #7 | langchain-odr | 1135 | 30% | |
| #4 | #8 | ii-researcher | 1095 | 24% | |
| #5 | **#1** | opencode | 1078 | 90% | ← 接地第 1,判官只给第 5 |
| #6 | #3 | camel-ai | 1040 | 55% | |
| #8 | #4 | deerflow | 1005 | 54% | |
| #12 | #12 | qx-agents | 442 | 1% | |

> 最典型的反转:**gpt-researcher 判官打第 2,但只有 3% 的引用能在沙箱里打开**;而 **opencode 接地最实(90%),判官只排第 5**。

### 1b) 模型榜(控制变量:同一套最小脚手架,只换基座 LLM)

这是更干净的对照实验——脚手架、工具、提示词全部固定,唯一变量是基座大模型。结果更强:

**ρ(判官 Elo, 接地) = −0.31(负相关)。**

| 判官排名 | 接地排名 | 基座模型 | 判官 Elo | 接地分 | |
|---|---|---|---|---|---|
| #1 | **#8** | qwen3-max | 1174 | **21%** | ← 判官第 1,接地垫底 |
| #2 | #6 | deepseek-v4-flash | 1156 | 27% | |
| #3 | #1 | glm-5 | 1013 | 59% | ← 接地第 1,判官第 3 |
| #4 | #2 | kimi-k2.5 | 1001 | 56% | |
| #7 | #3 | minimax-m2.5 | 910 | 46% | |
| #8 | #4 | qwen3-32b | 823 | 37% | |

> 在控制变量下,**判官最偏爱的 qwen3-max 接地排名垫底(21%),接地最好的 glm-5 判官只给第 3**。秩相关为负。

### 为什么这个发现重要
- 现在主流的深度研究评测大多是"让一个更强的 LLM 当裁判"。本结果给出**直接的反例证据**:裁判会被流畅、自信、看起来有据的文本带偏,而这些文本的引用可能根本不存在或打不开。
- 把"读起来好"和"内容站得住"**拆成两个正交的轴去测**,本身就是一个有信息量的实验设计;固定脚手架只换 backbone 的对照,把"是模型而非框架在制造这种解耦"这件事坐实了。

## 发现二:判官流水线里的"静默 error→平局"是一个隐藏混淆

- 现象:判官 API 调用失败时,代码把它**静默计为平局(TIE)**,导致平局率虚高到 **51%**——看上去"很多对战分不出胜负",实则是错误被吞掉了。
- 修复后(真正区分"判官判平" vs "调用出错"),在全部 **1,553 场对战**上重判,平局率降到 **17%**。
- 价值:这是一个对任何做 **LLM 陪审 / LLM-as-judge** 的人都成立的**方法学警示**——错误处理会污染平局率和置信区间。我们把"按干净计数而非按对战计数来核验陪审"固化为流程。

## 发现三:大多数候选质量信号要么是"死的",要么可注水

在 8 路区分力分析里,我们系统检验了所有候选打分信号能否真正把系统区分开:
- **死信号**:`claim_nli`(声明蕴含)在 98.9% 的打分文件中为 0(345/349,mean 0.0034),功能上无区分力,丢弃。
- **可注水信号**:字数、引用条数、原始排版分——可以靠"堆量"刷高,不反映质量,丢弃。
- **仅有的合法可区分信号**:**引用可达率(reachability)** 与 **长度归一化后的 presentation**。
- 同时诚实记录:顶部几个能干的系统**确实彼此接近**,不是噪声造成的假分离;且 box 上打分覆盖不均(部分 agent 任务覆盖少),需要统一重打分(见下一步)。

价值:这给"复合分该用哪些信号"提供了实证依据,而不是拍脑袋加权;也解释了为什么很多 DR 榜单"谁都差不多"——它们用的多半是可注水或无区分力的信号。

## 方法贡献:真值门控 Elo(Truth-gated Elo)

基于上面的发现,我们把排序口径锁定为:

```
headline = 判官 Elo  ×  接地门
gated_score = round( Elo × (reachability% + quote%) / 200 )
```

设计要点:
- **接地门判官无关**:可达率/引文核实通过 `build_sandbox_cache.py`(整库爬一次不可变沙箱)+ `score_grounding_from_cache.py` 计算,**不调用判官 API**,因此不会被"用一个 LLM 评另一个 LLM"的同源偏差污染。
- **不剔除任何系统**:接地以独立列展示,让"判官 vs 接地"的背离公开可见,而不是悄悄把谁踢出榜。
- **抗刷榜**:一个写得再流畅、但引用不可达的系统,门控后分数被压到很低,**无法登顶**。这正好把发现一里的反转纠正过来。

这套口径已在线上落地:https://www.deepresearcharena.com (框架榜 + 新的 `/models` 模型榜)。

## 诚实的局限(必须向老师讲清楚)

1. **样本量小,相关系数尚不显著**:框架榜 n=12、模型榜 n=8。ρ=0.32 / −0.31 在这个 n 下都达不到统计显著。**目前应当把它当作一个强假设 + 大量具体反转案例,而不是已被证实的定量定律。** 真正的支撑是"判官第 1 接地垫底"这类**定性反转在两张榜上稳定复现**。
2. **接地分覆盖不均**:部分 agent 在 box 上被打分的任务数偏少,可比性需要靠统一重打分补齐。
3. **模型榜只有 24/30 个任务**:有 7 个任务(0032-0038)因判官 API 两个账号都欠费暂时无法重判;补齐后样本更稳。
4. **接地 ≠ 正确**:可达率/引文核实衡量"引用是否真实存在且确实包含所引内容",不直接等价于"结论正确"。结论级正确性靠 must-cite recall + 证据门补充,这条还要继续打磨。

## 下一步实验(直接针对上面的局限,目标是把发现做"实")

> 这些是为了把"假设"升级成"显著结论",而不是加新功能。

1. **扩规模做显著性(最高优先)**:把评测扩到 **30+ 任务 × 全部系统**,在更大样本上重新估计 ρ(判官 Elo, 接地) 及其置信区间,检验"模型榜上的负相关"是否显著。这是验证主发现的关键实验。
2. **统一重打分 + 分数入库**:在稳定沙箱上对全场做一致打分,把 canonical 分数 cache 进仓库,使整个基准**离线可复现**,不再依赖脆弱的活 box。
3. **补判 + 补任务**:判官账号充值后补判 0032-0038(模型榜 24→30),并把框架陪审从 2 判官回退升回真 3 判官。
4. **人类对齐(可信度锚)**:用已上线的 `/annotate` 收成对人类偏好,算 **judge-vs-human 的 Cohen's kappa** 和"接地分 vs 人类排名"的相关——回答"到底判官更像人,还是接地分更像人"。
5. **扩任务到约 122**:补 22 个对抗任务(causal_debunking / contradiction / long_tail)的 golden + 论坛语料扩展,覆盖非技术主题,让"接地"的考察更全面。

## 一页纸结论(给老师)

- **做了什么有价值的事**:把深度研究评测拆成"判官偏好"和"引用接地"两个正交轴去量化,并设计了固定脚手架只换基座 LLM 的对照实验。
- **发现了什么**:两个轴是解耦的;在控制变量下甚至**负相关**——判官最偏爱的基座模型引用最不可达。说明纯 LLM-as-judge 的 DR 榜单可被流畅的编造刷榜。
- **据此做了什么**:提出并上线**真值门控 Elo**(判官 Elo × 判官无关的接地门),把这种解耦纠偏并公开展示,且能抗刷榜。
- **诚实地说**:样本还小、尚不显著,主要靠稳定复现的定性反转支撑;下一步就是扩到 30+ 任务做显著性 + 人类 kappa 锚定。

*数据来源:线上 `leaderboard_deep_v3.json`(框架榜)与 `leaderboard_models_v3.json`(模型榜,24 任务 / 643 场对战),2026-06-09 取数。*
