What it takes to build a rigorous Deep Research evaluation, and where we stand

A reproducible arena that scores long, cited research reports needs ten components working together. This plan maps each component, marks our current state honestly, and lays out the path to a credible, defensible benchmark. Our differentiator is the grounding truth-gate; our biggest gaps are corpus coverage and human-label validation.

Gap analysis: what stands between us and a credible benchmark

Ordered by how much each blocks external trust in the numbers.

A · Corpus coverage blocker

The forum corpus is tech-only, so coffee/fitness/photography/gardening tasks have no matching threads. Agents then cite off-topic or fabricate, and the golden built from that corpus is itself contaminated. Until the corpus covers every task topic, tasks 0002-0005 are only valid on the shopping + wiki sources.

B · Human-preference labels blocker

We validate the judge with LLM-only proxies (strong: 0.85 on LLMBar). But a credible eval needs a human-preference seed set with chance-corrected kappa, plus a JudgeBench/RewardBench number, to certify alignment on hard strong-vs-strong pairs.

C · Reference reports scoring

The strongest report-quality method (RACE) scores each report against a committed high-quality reference. We score vs peers only. Authoring 1-2 reference reports per task type unlocks reference-anchored scoring and few-shot calibration.

D · Reproducible release provenance

Content-hash + version the corpus, task set, judge prompts and model IDs; publish a datasheet / eval factsheet; pin seeds; release run logs. This is what lets others reproduce and cite the arena.

E · Contamination check tasks

Confirm a base model cannot answer tasks closed-book or from snippets alone, so we measure research ability, not memorization.

F · Harness containerization harness

Per-task containerized isolation + a formal agent-vs-infra failure taxonomy so a timed-out call is never scored as poor agent quality (the qx/storm/ii lesson, partly addressed).

Roadmap

Phased plan. P1 is the credibility-unblock; P2-P3 complete scoring + validation; P4-P5 harden + scale. Items marked sandbox-gated need the my5090 box up.

P1 · Corpus + reproducible release unblocks credibility

sandbox-gated · highest leverage
  • Seed forum + product + wiki content for every task topic (coffee, fitness, photography, gardening); re-crawl golden so it matches the corpus.
  • Content-hash and version the entire corpus; record the Wikipedia dump date; ship as a Docker snapshot.
  • Add a coverage audit: assert every task's gold answer exists in-sandbox; drop or fix tasks that fail.
  • Publish a datasheet / eval factsheet and pin judge model IDs + prompts + seeds.

P2 · Reference-anchored quality scoring

offline + judge API
  • Author 1-2 committed reference reports per task type; wire RACE-style reference-anchored pairwise scoring.
  • Add per-task adaptive rubrics (mandatory vs optional criteria), folded into the Bradley-Terry margin.
  • Keep length/style control; add the Arena-Hard style-control regression as a second debias.

P3 · Human + meta-eval validation

needs human annotators + judge API
  • Collect a human-preference seed set on a task subset (expert annotators); report Cohen kappa / Krippendorff alpha and judge-vs-human agreement.
  • Run our judge config against JudgeBench + RewardBench for a transferable, externally-comparable human-agreement number.

P4 · Harness hardening

sandbox-gated
  • Containerized per-task isolation; reinstall all framework venvs on the box; re-run every framework on a stable sandbox.
  • Formal agent-vs-infra failure taxonomy; cost / token / latency accounting on the leaderboard; release trajectory logs.

P5 · Scale + polish

paper-facing
  • Scale to 30+ tasks x more agents; report separability + rank-significance; power analysis for CI width.
  • Expand the bilingual split; consider an evergreen task-refresh cadence to fight contamination.
  • Surface methodology transparency + per-agent profiles + the grounding-gate reorder story on the public site.
