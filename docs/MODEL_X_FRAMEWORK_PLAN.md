# DeepResearchArena 规划文档:模型 × 框架 评分矩阵

> 定稿日期:2026-06-05 · 状态:用户已确认方向,所有在跑实验已暂停,待本文档评审后按优先级恢复

## 1. 一句话目标

DRA 的评测对象是 **(框架 F, 模型 M) 组合**:同一批沙箱任务上,给矩阵中每个单元格打出
**真值门控评分**,从而能分解出"框架带来多少、模型带来多少、二者如何交互"。

## 2. 评分铁律(已锁定,任何重建不得回退)

1. **主排序 = 真值门控 Elo = 判官 Elo × 接地门**(接地门 = 引用可达率与引文核实率的均值,
   判官无关、按冻结沙箱缓存核验)。流畅的编造永远不能登顶。
2. **每个单元格都有分有排名,不排除任何组合**;差的沉底,绝不消失。
3. **裸判官 Elo 仅作为切换页签存在**(展示"裸判官会被骗"),接地两列永远可见。

## 3. 矩阵当前覆盖(2026-06-05 实测数据)

覆盖结构 = "十字形":v4-flash 一整列(框架轴)+ eff 一整行(模型轴)。两个主效应已可读:

- **框架效应 ≫ 模型效应**:同一模型(v4-flash)下框架把接地从 0.03 拉到 0.55(约 18 倍);
  同一脚手架(eff)下换模型只有 0.21 到 0.37(约 1.8 倍)。
- **坏框架是负资产**:gpt-researcher/storm/ldr 把 v4-flash 拉到裸基线(0.267)以下。
- **模型轴反直觉**:中杯稠密 qwen3-32b 第一(0.369),旗舰 qwen3-max 垫底(0.208,
  引用更多但编造比例更高)。
- **缺的是交互项**:好框架的优势跨模型稳不稳、坏框架能否被好模型救回,只能靠填格回答。

  PoLL(arXiv 2404.18796)、CalibraEval(arXiv 2410.15393)。
