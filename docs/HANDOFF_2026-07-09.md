## 2. The one finding that reframes everything

`_search_shopping` returned `[]` on every query, on every stack, for the life of
the project.

The gateway dials Magento at `http://shopping:80` (the compose service name --
`infra/release/compose.yml:68` says so, this was never a box mistake). Magento
answers only to its `base_url`, replying `302` to that address and **dropping the
query string**. That address is a closed port inside the compose network, so
`requests` (which follows redirects) raised `ConnectionError`, and the handler
returned `[]`. The guard was `if r.status_code >= 400`. A 302 never trips it.

An unreachable store and a store with no match for the query produced
byte-identical data. `fact` grades price and rating claims that only the store can
support: it read 0 on 92.7% of reports, and that was written up as narrative style
and "the cost of decidable scoring". It was a redirect.

**No score published before today used a three-site corpus.** Two sites were up.

Full write-up: `internal/docs/STORE_NEVER_SEARCHED_2026-07-09.md`.

## 7. Traps

These cost me hours. They will cost you the same.

**A test whose fixture cannot vary the thing under test is not a test of that
thing.** `tests/test_nav_citation_parity.py` originally used only a *product*
fixture, whose served spelling already equals its registry canonical. That is
exactly why it could not see the `served`-set bug in the very fix it was written
for. Vary the source: product, wiki, forum.

**A check that is only correct where it never runs is not a check.**
`check_sources_alive()` already asserted "every source answers a canned query". It
was written, marked box-only, skipped on the workstation, and never run on the
box. It would have caught the store on day one.

**`ast` walks are blind to `exec`'d driver strings.** `tongyi_runner` and
`ldr_runner` build their agent loops as Python *source strings* and `exec` them in
subprocess venvs. My first `sampling_parity` rule was an `ast` walk: it flagged
storm and costorm and walked straight past `tongyi_runner.py:153`. `check_parity`
scans *text* over `_strip_prose` for exactly this reason, and its own docstring
warns about it. Widening the `wiki_url_rewrite` rule this way immediately found a
live copy the audit had not named.

**Deleting an injection from one runner does not delete it.** The wiki rewrite
was removed from `ldr` and `local_deep_researcher`, whose comments still explain
why -- and survived in three other reachable entrypoints, including `ldr_runner`'s
own driver string.

**Fixing in one proxy equalises one lane.** `_setup_ds_backbone` points eleven
lanes at `ds_proxy` (:8088); only `claude-code` goes through `llm_gateway`
(:8100). Check which door the traffic actually uses before you congratulate
yourself.

**Withhold, never zero.** When the instrument did not observe something, the
metric is `available=False` with a reason. Scoring it `0` is a false accusation.
`pof` is withheld for: no evidence log, `fetch_observable=false`, a damaged log,
and a log with records lost to `_unattributed.jsonl`.
