# Goal: 榜单两大属性 + 七道闸门（收敛版验收标准）

交给 Codex / 单体 agent 执行。**终止条件是下面七道闸门全部变绿并保持绿，
不是"审计挑不出问题"。** 闸门都是确定性脚本，跑一遍成本≈0，可以无限重跑。

## 榜单要成立的两大属性（闸门为此服务）

**A. 对比公平且差异可见。** 所有车道在同等协议下跑（同预算、同提示词、
同底模接入、同上下文上限）。凡是做不到同等的——框架天生缺某工具、
上下文上限不同、必须走特殊适配——不许悄悄容忍，必须进 lane_protocol
声明并在榜单前端渲染成脚注/徽章。**没有未声明的特殊条件。**

**B. 每个低分都可归因到框架自己的行为。** 分低必须是"它确实没做到"，
拿得出证据（没引用、没取到页、数字写错），而不是仪器没看见。历史冤案
（商城 302 全员 fact=0、页面双拼法判成幻觉、gpt-researcher 适配层坏）
一律属于闸门要焊死的缺陷类。

## 冻结令（先于一切）

1. 打分语义冻结。公式、权重、口径、门控一律不改。
2. 执行中发现"语义层面不合理"的东西，**不修**，记入 `docs/SPEC_ISSUES.md`
   一行一条，等用户拍板。只修"实现与既定语义不符"的 bug。
3. 每修一个 bug，必须配一个在旧代码上会红的回归测试，且 fixture 必须
   横跨商品 / 维基 / 论坛三源（教训见 HANDOFF_2026-07-09.md §陷阱1）。

## 七道闸门（全部做成 pytest / preflight 常驻项）

**G0 协议对等与差异披露（属性 A 的闸门）**：
- 每条车道有 `lane_protocol` 声明（预算、提示词、底模端点、上下文上限、
  工具面），开跑前脚本断言实测值与声明一致（R-3 已有底子，补全到全车道）。
- `check_parity.py` 15 条规则全过之外，新增"披露完备性"检查：任何车道与
  基准协议的差异（上下文更小、缺某工具、走特殊 shim）必须在
  `lane_protocol.deviations` 里列出，且榜单 JSON 里带出该字段，前端渲染成
  脚注。**存在未声明差异 = 闸门红。**
- 已知必须披露的存量差异先登记：各框架上下文/compact 能力差异、
  gpt-researcher 检索器状态、8/12 车道 fetch withhold。

**G1 oracle 顶格（100 题）**：按每题答案键机械生成"神谕报告"（每条 vital
事实带同行引用；概念轴带页面真实引文，用箱上 page cache），每题必须
completeness = 1.0、fact > 0、reach = 1.0。
现成底稿：scratchpad 的 oracle_audit.py。已知欠账：商品名含 `[...]` 的
链接解析 bug（`iter_markdown_links` 未吃到 MD_LINK_RE 修复），修完 G1 才可能绿。

**G2 空壳归零（100 题）**：无任何可核查内容的报告，每轴必须 0。

**G3 扰动必降**：每题从神谕报告采样若干腐蚀版本（改错一个数字 / 删掉一条
引用 / 换错一个 URL），对应轴分数必须严格下降。专杀"静默归零/静默满分"类缺陷。

**G4 withhold 不打 0**：枚举所有仪器缺失路径（无 fetch_log、无 page cache、
日志损坏、fetch_observable=false），断言一律 `available=False + reason`，
绝不产出 0 分。0 分必须永远意味着"观测到了且确实差"。

**G5 箱上 preflight 真实通过**：`check_sources_alive()` 等 box-only 检查在
my5090 上实际跑一遍全绿（三源对固定查询非零命中）。不许再有"只在它从不
运行的地方才正确的检查"（教训见陷阱2）。

**G6 端到端冒烟无静默零**：2 个模型 × 全部可跑车道 × 3 题，每个
(lane, axis) 单元无 NaN、无无解释的 0——每个 0 都带 machine-readable 原因码。

## 预算纪律

- 禁止 audit 型 agent fan-out。闸门是脚本，不是 LLM。
- 允许的 LLM 用量：单体 agent 顺序干活;最多在七道闸门绿了之后，
  开**一个 ≤6 agent** 的对抗扫描做终验，仅此一次。
- 箱上跑的东西用本地 vllm / 百炼 flash 档，不动昂贵模型。

## 交付

七闸全绿 + `pytest -q` 全绿 + 一份 ≤1 页的 `GATES_GREEN_REPORT.md`
（每道闸门的证据路径）。之后才允许启动 #39 全量首跑。
